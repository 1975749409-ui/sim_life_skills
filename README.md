# sim-life · 极致真实模拟人生写作

> 一个 Claude Code 技能（Skill）：让 Claude 帮你"真实地过完一个人的人生"。
> 生活模拟器 × 现实主义文学——以第三人称白描逐天记录，细节到挤地铁、犹豫吃什么、上厕所。

## 这是什么

把"模拟人生"玩成文字。你捏一个角色、设定一个世界，然后每天做出选择（穿什么、回应谁、去哪里），Claude 把一天"极致真实"地写出来——包含大量不值得写但真实存在的生活瞬间。日子一天接一天，**以前发生的事会影响以后**：你帮过的人会记得你，你得罪的人不会消失。

它同时是：

- **生活模拟器**：有机制保证一致——角色档案版本化、关系图谱、待跟进事项、时间线归档，故事跨很多天、很多次会话都不会崩设定。
- **现实主义文学**：有文风保证真实——拒绝主角光环、巧合救场、完美应对；拥抱平庸、尴尬、失败与延迟的因果。

## 特性

- 🎲 **看不见的骰子**：事件是否发生 = 性格 × 场合 × 状态 × 关系累积 × 随机，不显式掷骰、不剧透概率
- 🎛️ **决策驱动**：每天 3 个生成选项 + 1 个自由输入；平淡日子 1-2 个决策点，重大日子 4-6 个
- 👗 **穿着影响事件**：穿搭内部标注醒目度与场合适配，惹眼穿着会提高被搭讪、被注意的概率
- 📁 **版本化人物档案**：角色状态只追加版本、从不覆盖，历史可追溯
- 🔗 **因果累积**：帮助、得罪、暧昧都沉淀到状态文件，持续影响未来，并在正文里"浮出水面"
- 📌 **待跟进事项**：吵架、欠钱、答应的事不会丢，第二天自然接上
- 🧍 **自动模式**：输入"今天全自动"，Claude 替主角过完一天，提交前给你预览
- 📅 **正文归档**：润色后的完整叙事按"月/周"分目录存放，标题 = 日期 + 一句话摘要，方便回看
- 🚫 **不读档重来**：除明确说"重置这一天"，坏结果照常入档并影响后续——真实感优先于爽感

## 安装

1. 将 `sim-life/` 文件夹复制到你的项目：
   - 项目级：`<你的项目>/.claude/skills/sim-life/`
   - 全局级（任何项目可用）：`~/.claude/skills/sim-life/`
2. 重启或新开一个 Claude Code 会话
3. 输入 `/sim-life` 启动

> 需要 [Claude Code](https://claude.com/claude-code)（命令行或桌面版均可）。

## 开始一段人生

### 1. 捏人建世界

`/sim-life` 启动后，Claude 会引导你：

1. **设定世界**：时代、地点、物价、技术水平、社会规则（支持任意自定义世界观）
2. **捏主角**：性别、外貌、身材、年龄、家庭背景；可选习惯/怪癖、人生目标
3. 归档到 `sim-life-data/`，进入第一天

### 2. 每天怎么玩

```
读档 → 开场简述 → 逐个决策点（3+1 选项）→ 提交确认 → 润色成文 → 归档
```

- 每个选项出现前，Claude 用两三句交代当前场景，让你有依据地选
- 一天结束后 Claude 问"今天的故事要提交吗？"——这里你还能补充/修改
- 确认后，Claude 把全天选择润色成完整叙事（补上吃饭、通勤、发呆），存入 `正文/`
- 想放手时，说一声 **"今天全自动"**，Claude 用骰子替你过完

### 3. 续写

任何会话里输入 `/sim-life` 或说"继续"，Claude 自动读档接上——时间推进由叙事自然度决定（普通日子快进但保留质感，重要日子细写）。

## 工作原理

### 数据目录

所有数据保存在项目根目录的 `sim-life-data/`：

```
sim-life-data/
├── world.md            世界设定（时代/地点/物价/技术/社会规则/特殊设定）
├── current.md          当前指针：日期/位置/进度 + 待跟进事项
├── relations.md        关系图谱：角色间关系与里程碑
├── characters/
│   └── <角色名>.md     每个角色一个档案文件，按版本追加（v1 → v2 → ...）
├── timeline/
│   └── <YYYY-MM-DD>.md 当天事实摘要（供快速读档）
└── 正文/
    └── <YYYY-MM>/      按月分子目录
        └── <YYYY-MM-DD> <简要>.md   完整叙事，标题 = 日期 + 一句话摘要
```

### 项目结构

```
.claude/skills/sim-life/
├── SKILL.md                        主流程（捏人 / 每日推进 / 续写）
└── references/
    ├── character-schema.md         人物档案模板（版本化规则）
    ├── world-schema.md             世界设定模板
    ├── realism-rules.md            现实主义写作规则（"极致真实"的核心）
    └── choice-system.md            选项机制（3+1、穿搭、大小事判定、自动模式）
```

### 核心循环

```
捏人 → 归档 → 读档 → 逐项选择 → 提交 → 润色成文 → 更新状态 → 续写 → ...
```

## 可自定义

- **正文分目录**：默认按月，可改为按周（改 SKILL.md 中对应说明即可）
- **选项密度**：平淡日 1-2 个 / 重大日 4-6 个，可自行调整
- **读档范围**：默认读最近 3 天正文，可扩大或缩小
- **世界观**：完全自定义，物价、技术、社会规则都会如实反映到正文

## 常见问题

**它会自己编出我不想要的剧情吗？**
所有关键决策都交给你（除非开启自动模式）。Claude 只负责在决策之间填充真实的生活质感，并让过去的因果自然浮现。

**能写黑暗/沉重的题材吗？**
支持自定义世界观。题材边界由你设定，随时可以喊停或重定向。

**正文越堆越多，会不会读不动？**
读档有明确范围上限（最近 3 天 + 最新状态 + 关系全文），老正文按需定向读取。
