# 关系图谱模板（relations-schema）

关系图谱保存在 `sim-life-data/<人生名>/relations.md`。

## 好感度系统

每对关系有**双向好感度**（-100 ~ 100，0 = 陌生人），是"看不见的骰子"的核心修正系数。

### 数值与档位（只用于内部记录与判定）

- 90+ 至亲 / 挚爱
- 70-89 深情 / 暧昧
- 50-69 密友
- 25-49 朋友
- 1-24 认识 / 顺眼
- 0 陌生人
- -1~-24 冷淡
- -25~-49 反感
- -50~-69 仇视
- -70 以下 敌意

### 影响因素（好感度从哪来）

- **初次印象**：颜值 / 装扮 / 气质 / 谈吐 → 首次见面的基准偏移（颜值高、穿着得体 → 初始正向；邋遢、冒犯 → 初始负向）
- **交流**：话题投缘、倾听、玩笑分寸、是否冒犯 → 每次交流 ±1-3
- **互动**：帮助 / 陪伴 / 共同经历 / 送礼（+）；冲突 / 怠慢 / 爽约 / 背叛（-）→ 日常 ±3-10
- **重大节点**：表白、救命之恩、彻底闹翻 → ±15-25
- **性格契合**：互补相吸、相似相斥 → 长期持续的小幅倾向
- **穿着**：醒目度与场合适配 → 影响初次印象与社交效果（见 `choice-system.md`）
- **时间**：久不联系 → 好感回落（浅交回落快，密友慢，至亲几乎不回落；负好感随时间淡化为陌生）
- **圈层口碑**：别人在背后说你 → 间接修正（同圈层会互相影响对你的看法）

### 变化规则

- **双向**：`主角→对方` 与 `对方→主角` 分开记录，可不对称（你很喜欢她，她对你一般）
- **有因有果**：每次变化在"影响因子"里记一笔，正文里必须有对应事件（见 `realism-rules.md` 的"因果浮出水面"）
- **幅度控制**：日常 ±1-3，实质互动 ±3-10，重大节点 ±15-25；越接近两端越难变（90+ 需长期积累，-70 以下需彻底决裂）
- **衰减**：约每 2-3 周不接触，浅交回落 5-10；密友慢；至亲几乎不回落
- **作用于结果**：好感度直接作为概率修正——对方好感越高，答应邀约 / 帮忙 / 和解的概率越高；告白成功与否主要看 `对方→主角` 的好感

### 行为化（正文规则）

- **正文绝不出现数字**：好感度是内部机制，叙事只用行为、神态、语气表达（"她犹豫了一下，还是点了头"）
- 好感高 → 主动找你、护着你、记住你说过的话；好感低 → 冷淡、回避、使绊、说风凉话

## 结构

```
# 关系图谱

## 圈层（谁认识谁）
- 家庭圈：
- 学校圈 / 工作圈：
- 朋友圈：
- 兴趣 / 社区圈：
- 老乡 / 旧识圈：

## 关系线（每对关系一条，可发生在任意两人之间）
### <甲> — <乙>（主角—NPC 或 NPC—NPC）
- 状态：<陌生人 / 朋友 / 密友 / 暧昧 / 恋人 / 反感 / 仇视 …>
- 好感度：<甲>→<乙> <数值> · <乙>→<甲> <数值>（-100~100）
- 情感倾向：<乙>怎么感受这段关系——被帮助后的感激 / 曾经的尴尬 / 淡淡的好感 / 别有所图
- 圈层：<属于哪个圈，便于涟漪传播>
- 影响因子：
  - <日期> <事件> ±<幅度>（例：07-03 帮捡文件 +8；07-08 冷场 -2）
- 里程碑：
  - <日期> <事件>

> NPC—NPC 的关系线是**张力的来源**：他们之间有什么，会决定主角被卷进什么样的事。
```

## 使用约定

- **圈层生成涟漪**：同一圈层的人互相认识——你帮了李静，她室友会知道；圈内口碑影响好感
- **情感倾向补充数值**：好感度告诉 Agent"多少"，情感倾向告诉"为什么"——决定未来的具体行为
- **新人物加入**：创建其档案时注明圈层，并按初次印象给一个初始好感（基准由颜值 / 装扮 / 谈吐决定）
- **离线近况**：长时间未接触的角色，可在其关系线下补一条"近况"（合理推演），并结算好感衰减
- **一致性**：好感度变化必须能在正文或 timeline 中找到对应事件，防止数字凭空跳动

## 角色之间的张力

张力 = 角色们"他们自己的事"，不需要主角在场也存在：

- **执念冲突**：NPC 有各自的小目标 / 执念，与主角目标或其他 NPC 目标冲突即生张力（都想升主管、都想追同一个人）
- **不对称**：他喜欢她，她喜欢你——三角天然有戏
- **圈内流言 / 站队**：圈层里有人背后议论、有人站队，主角会被打听、被夹在中间
- **秘密**：NPC 之间藏着彼此不知道的事，被撞破就是戏剧

张力要**溢出到主角身上**：主角被卷进站队、被打听、被牵线、被要求表态——这比主角主动去找事真实得多。
