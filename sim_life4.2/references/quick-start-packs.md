# 一键开局包（quick-start-packs）

点开即玩。每个包 = **世界观 + 主角预设 + 初始人物 + 开局情境**，一键写入存档，直接开始第一天，不用捏半天。

## 使用方式

1. 新建人生时选"快速开局"
2. Agent 列出全部包，用户挑一个（可先看简介）
3. Agent 把包写入存档：`world.md` ← 世界观；`characters/<主角名>.md` v1 ← 主角预设；初始人物各建档案；`current.md` ← 开局日期/位置/待跟进/临近日程/经济
4. 用户可微调任意字段，或直接说"开始第一天"
5. 之后所有机制照常生效（沙盒 / 选项 / 自动、看不见的骰子、归档……）

> 包是起点不是剧本：开局后一切照常演化，人设只是种子。
> 每个包的初始人物都带**初始好感度**（对方→主角），开局即可见人情冷暖；好感度规则见 `relations-schema.md`。
> 幻想 / 跨文化包同样遵循"极致真实"：魔法也好、修真也好，日子依然是柴米油盐——仙侠里是挑水劈柴赶集，西幻里是揉面喂马去公会排队（见 realism-rules 的"拥抱平庸"）。

## ① 1990 年代县城

**世界观**：1990 年代初北方小县城，下岗潮前夜。一碗面 2 元、公交 5 毛、房租 50 元/月，普通工人月收入约 150 元。有线电话稀少、BP 机、录像厅；没有网络和手机。单位分房、人情社会、找关系办事。县城就那么大，谁都认识谁。

**主角预设**：林小满，18 岁女，高中刚毕业没考上大学，县棉纺厂学徒工。个子不高，两条辫子，笑起来有虎牙。父亲是厂里老钳工、沉默寡言，母亲在菜市场摆摊。性格闷但嘴硬心软；说话短句，爱用"咋""得嘞"。技能：织布机上手快、心算灵。习惯：睡前把口袋里的零钱数一遍。目标：攒钱翻修家里的屋顶。经济：学徒工资 40 元/月，身上 12 元。

**初始人物**：父亲林国强（厂里钳工，话少）·好感 82、发小张铁柱（顶替父亲进厂，混不吝，总想拉你去录像厅）·好感 72、车间组长王桂芬（爱管闲事的大姐）·好感 45。

**开局情境**：第一天早班，天蒙蒙亮，母亲在灶台前叫醒你。今日日程：06:30 进车间，07:00 学徒排线上手。眼下：下月发工资要给家里买台缝纫机。临近日程：月底厂里评先进，学徒也能评。身心状态：早起有点困，精神一般。主线：攒钱翻修屋顶 + 想证明自己不只是"没考上大学的丫头"。
