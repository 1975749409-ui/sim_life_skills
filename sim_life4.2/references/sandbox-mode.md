# 沙盒自由模式（sandbox-mode）

**默认交互模式**：自由行动。选项不再是主导，而是可召唤的辅助。

## 核心理念

- 现实里没有"现在给你三个选择"这回事——人就是过日子，然后承担后果
- Agent 连续叙事，一天像流水一样自然推进，不再被"决策点"切成片段
- 你随时自由输入主角的动作、对话、态度，甚至"什么都不做"
- **你决定"做什么"，看不见的骰子决定"结果如何"**——人生不可控，这是写实的核心

## 一天的节奏（沙盒版）

1. Agent 开场简述后，开始连续叙事当天
2. 在每个**有意义的节点**（起床、午休、收到消息、下班、睡前…）自然停顿，提示"此刻你想做什么？"——这是邀请，不是 A/B/C 轨道
3. 你自由输入行动；Agent 把行动落地到世界，用骰子决定结果并继续推进
4. 一天走完 → 提交确认 → 润色成文 → 归档（与常规流程一致）

> **决策节拍**见 `choice-system.md`：每天保证足够的决策点交给你；Agent 只自动填不值得选的细节，不替你决定"值得犹豫"的事。

## 自由输入的语义

你输入的一切都是**主角的权威行动**，Agent 不得改写或忽略：

- 动作指令："去楼下便利店买包烟""逃课去网吧"
- 对话内容："我回复她：周末可以"
- 态度 / 心情："我今天想摆烂""不想去上班，请假"
- 什么都不想干："今天没什么想做的，你编吧"（Agent 自动过）

Agent 的职责：把行动落地到世界中、用看不见的骰子决定结果、连续叙事。

## 骰子管结果

- 你去告白 → 骰子决定顺遂或尴尬；你约她 → 骰子决定答不答应
- 结果仍受性格、状态、关系累积、场合影响（见 `choice-system.md` 的"看不见的骰子"）
- 结果照常走"大小事判定"决定是否入档

## 选项作为召唤式辅助

- 默认不出现选项
- 你拿不定主意时说"给我几个选项" / "我该怎么办"，Agent 才亮出 A/B/C（3+1，含"平凡/怯懦选项"规则，见 `choice-system.md`）
- 呼出选项后，仍可随时改自由输入
- 选项只是扶手，不是轨道

## 与自动模式的关系

- **自动模式**：你完全放手，Agent 用骰子过完一天（提交前给预览）
- **沙盒**：你随时伸手推一把，其余让世界自己走
- 三种交互（沙盒 / 选项 / 自动）随时可切换，无硬性边界
