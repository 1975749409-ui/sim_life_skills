# sim-life-4.2 · 极致真实模拟人生写作

> 一个 Claude Code 技能（Skill）：让 Claude 帮你"真实地过完一个人的人生"。
> 生活模拟器 × 现实主义文学——以第三人称白描逐天记录，细节到挤地铁、犹豫吃什么、上厕所。

## 这是什么

把"模拟人生"玩成文字。你捏一个角色、设定一个世界，然后按你的意思过每一天——想干嘛就输入什么（穿什么、回应谁、逃课还是躺平），Claude 把一天"极致真实"地写出来，看不见的骰子决定结果。包含大量不值得写但真实存在的生活瞬间。日子一天接一天，**以前发生的事会影响以后**：你帮过的人会记得你，你得罪的人不会消失。

它同时是：

- **生活模拟器**：有机制保证一致——角色档案版本化、关系图谱、待跟进事项、时间线归档，故事跨很多天、很多次会话都不会崩设定。
- **现实主义文学**：有文风保证真实——拒绝主角光环、巧合救场、完美应对；拥抱平庸、尴尬、失败与延迟的因果。

## 特性

- 🎲 **看不见的骰子**：事件是否发生 = 性格 × 场合 × 状态 × 关系累积 × 随机，不显式掷骰、不剧透概率
- 🎮 **沙盒自由模式**：默认连续叙事，你想干嘛就输入什么（逃课、告白、躺平都行），看不见的骰子决定结果；拿不定主意时说"给我几个选项"才亮出 A/B/C
- 👗 **穿着影响事件**：穿搭内部标注醒目度与场合适配，惹眼穿着会提高被搭讪、被注意的概率
- 📁 **版本化人物档案**：角色状态只追加版本、从不覆盖，历史可追溯；支持勘误与版本封档
- 🔗 **因果累积**：帮助、得罪、暧昧都沉淀到状态文件，持续影响未来，并在正文里"浮出水面"
- 📌 **三支柱连续性**：待跟进事项管过去的线，待办系统管现在与未来，经济账本约束当下——旧线不丢、约定按时提醒、钱永远是个现实约束
- 🔔 **待办提醒系统**：今日日程 + 短期待办 + 长期待办三层；每天开场先提醒"今天几点上课、约了谁几点见"；新约定即入账，逾期转待跟进
- 🧩 **人生阶段**：学生、上班族、失业者、退休老人的日子结构完全不同，阶段切换自动适配
- 📈 **能力成长**：兴趣/技能随岁月缓慢进步，活十年的人跟活十天的人不一样
- 🗣️ **说话方式**：每个角色有自己的口头禅、句式与语速，对话有辨识度
- 🌐 **群像离线活动**：NPC 也有自己的生活，再见面时那些日子会留下痕迹
- 🌦️ **天气与星期连续**：不每天随机，季节影响细节与事件
- 🧍 **自动模式**：输入"今天全自动"，Claude 替主角过完一天，提交前给你预览
- 📅 **正文归档**：完整叙事按"月/周"分目录存放，标题 = 日期 + 一句话摘要，每月自动维护索引
- 🗃️ **多人生存档**：一个项目可并行开多个"人生"，各存各的档
- 📖 **人生年表与回望**：重大节点记入年表，月末/年末生成主角视角的"回望"，岁月有重量
- 🎲 **事件池**：随机事件从类型池抽取（日常/社交/冲突/机会/意外），防重复套路
- ⏳ **时间纵深**：年龄、健康随岁月推进；重大健康事件与终局都有处理规则——离世是人生的一部分
- 🌐 **人际圈层**：关系按生活圈组织，流言与人情在圈内传播，帮助会引发涟漪
- 💥 **插曲机制**：平淡日子里偶有突发事件打断节奏，逼出紧急选择
- 👁️ **视角切换**：重大时刻偶尔聚焦配角，世界更立体
- 🌫️ **记忆与遗忘**：久不联系的关系自然淡化，旧细节会触发遗忘多年的回忆
- 📤 **导出/传记模式**：一键把一段人生拼接成可通读的传记文档
- 🧰 **一键开局包**：内置 21 个世界观（县城/校园/北漂/民国/小镇/工厂/日/美/韩/港/台/北宋市井/武侠/赛博朋克/蒸汽朋克/废土/火星/仙侠/西幻/异世界转生…），配套主角/初始人物/开局情境，点开即玩，不用捏半天
- ⚖️ **困难题材指南**：沉重内容尊重而克制，节奏由你掌控
- 🔍 **一致性自检**：归档后自动核对各文件，防止设定悄悄跑偏
- 💞 **好感度系统**：关系有双向数值（-100~100），受颜值初印象、交流、互动、时间、圈层口碑影响；只通过行为显现，正文不出现数字
- 🧬 **身心状态系统**：饱腹/睡眠/精力 + 健康疾病 + 情绪心理，全是骰子修正系数——饿着会顶嘴，病着会请假，焦虑会搞砸
- 🗺️ **故事线追踪**：主线/支线显式跟踪进度与下一步触发，重要的事不会被忘
- 📆 **日历与纪念日**：生日/节日/纪念日自动成为重要日子，提前提醒；记住你生日的人好感度大升
- 🌍 **世界大事件**：时代冲击（下岗潮/裁员潮/流行病）按时间触发，作为背景板自然浮现；**默认关闭**，开局时询问是否开启
- 💰 **月度经济结算**：跨月自动结算收支、房租、通胀
- 🕶️ **机制隐藏**：所有系统都藏在档案里，正文只通过行为、神态、环境让你感知——绝不弹进度条
- 🎲 **随机开局**：说"随机"，Claude 自发生成一个自洽的世界 + 主角 + 主线
- 🖋️ **文风切换**：冷叙述 / 幽默 / 诗意，随你口味
- 🔍 **记忆检索**：正文调用旧事时定向搜索档案，不凭空编造
- 📊 **一生统计**：认识多少人、攒下多少钱、看过多少次日落，传记时呈现
- 🌱 **人物演化**：性格、爱好随经历改变，并标注"何时·因何"改变
- 👤 **角色口吻**：每个角色的口头禅/句式被严格守住，自检时抽查
- 🌊 **世界会找上门**：每天至少一件世界主动发生的事——事件池/NPC 上门/环境变化，不用你开口
- 🔄 **NPC 自治与回访**：NPC 有自己的生活与出现节拍，超过 7 天没出现就会重新浮现；归档时全部角色一起更新
- ⚔️ **角色张力**：NPC 之间有他们的关系与冲突（站队/流言/三角），会把你卷进去
- 🎯 **决策节拍**：平淡日 3-4、重大日 6-8 个决策点交给你；Agent 只填不值得选的细节，不替你决定"值得犹豫"的事
- 🚫 **不读档重来**：除明确说"重置这一天"，坏结果照常入档并影响后续——真实感优先于爽感

## 安装

1. 将 `sim-life-4.2/` 文件夹复制到你的项目：
   - 项目级：`<你的项目>/.claude/skills/sim-life-4.2/`
   - 全局级（任何项目可用）：`~/.claude/skills/sim-life-4.2/`
2. 重启或新开一个 Claude Code 会话
3. 输入 `/sim-life-4.2` 启动

> 需要 [Claude Code](https://claude.com/claude-code)（命令行或桌面版均可）。

## 开始一段人生

### 1. 捏人建世界

`/sim-life-4.2` 启动后，Claude 会引导你：

1. **一键开局**：从 7 个开局包挑一个直接开玩（世界观 + 主角预设 + 初始人物 + 开局情境都配好了）
2. **从零设定**：或自己捏——设定世界（时代/地点/物价/技术/气候/社会规则）+ 捏主角（性别/外貌/身材/年龄/人生阶段/家庭/说话方式/兴趣技能）
3. 归档到 `sim-life-data/<人生名>/`，进入第一天

### 2. 每天怎么玩

```
读档 → 开场简述 → 沙盒自由推进（随时输入行动，骰子定结果）→ 提交确认 → 润色成文 → 归档
```

- 默认没有选项：Claude 连续叙事，像流水一样过日子；**你想干什么就直接输入**——逃课、告白、躺平都行，说了就做
- 每天开场 Claude 会**先提醒你今天的日程与待办**——几点上课、约了谁几点见、近期要交什么（存进 todos，长期短期分开管）
- 你决定"做什么"，看不见的骰子决定"结果如何"——人生不可控，这才是真实
- 拿不定主意时，说一句 **"给我几个选项"**，Claude 才亮出 A/B/C
- 一天结束后 Claude 问"今天的故事要提交吗？"——这里你还能补充/修改
- 确认后，Claude 把全天选择润色成完整叙事（补上吃饭、通勤、发呆），存入 `正文/`
- 想完全放手，说 **"今天全自动"**，Claude 用骰子替你过完

### 3. 续写

任何会话里输入 `/sim-life-4.2` 或说"继续"，Claude 自动读档接上——时间推进由叙事自然度决定（普通日子快进但保留质感，重要日子细写）。想通读一段人生，说"导出 / 传记"，Claude 会把正文拼接成一份完整传记文档。

## 工作原理

### 数据目录

所有数据保存在项目根目录的 `sim-life-data/`（每个"人生"一个存档文件夹）：

```
sim-life-data/
└── <人生名>/                一个"人生"一个存档，可并行多个
    ├── world.md            世界设定（时代/地点/物价/技术/社会规则/气候/世界大事件）
    ├── current.md          当前指针：日期/天气/进度 + 身心状态 + 待跟进 + 今日提醒 + 经济账本
    ├── todos.md            待办与日程：今日日程 + 短期待办 + 长期待办 + 节日纪念日 + 变化日志
    ├── threads.md          故事线追踪：主线/支线进度与下一步触发
    ├── 年表.md             人生编年史：重大节点 + 月/年回望
    ├── relations.md        关系图谱（含圈层）：角色间关系与里程碑
    ├── characters/
    │   └── <角色名>.md     每个角色一个档案文件，按版本追加（v1 → v2 → ...）
    ├── timeline/
    │   └── <YYYY-MM-DD>.md 当天事实摘要（供快速读档）
    └── 正文/
        └── <YYYY-MM>/      按月分子目录
            ├── 索引.md      当月正文索引
            └── <YYYY-MM-DD> <简要>.md   完整叙事，标题 = 日期 + 一句话摘要
```

### 项目结构

```
.claude/skills/sim-life-4.2/
├── SKILL.md                        主流程（捏人 / 每日推进 / 续写）
└── references/
    ├── character-schema.md         人物档案模板（版本化、勘误、封档）
    ├── world-schema.md             世界设定模板（含气候）
    ├── realism-rules.md            现实主义写作规则（"极致真实"的核心）
    ├── choice-system.md            选项机制（3+1、平凡选项、穿搭、自动模式）
    ├── sandbox-mode.md             沙盒自由模式（默认交互）
    ├── body-mind.md                身心状态系统（饱腹/睡眠/健康/情绪）
    ├── event-pool.md               事件池（随机事件的选材库）
    ├── relations-schema.md         关系图谱模板（双向好感度 + 圈层 + 情感倾向）
    ├── quick-start-packs.md        一键开局包（世界观 + 主角 + 人物，点开即玩）
    └── life-stage.md               人生阶段日常模板（含终局规则）
```

### 核心循环

```
捏人 → 归档 → 读档 → 自由行动 → 提交 → 润色成文 → 更新状态 → 续写 → ...
```

## 可自定义

- **正文分目录**：默认按月，可改为按周（改 SKILL.md 中对应说明即可）
- **选项密度**：平淡日 1-2 个 / 重大日 4-6 个，可自行调整
- **读档范围**：默认读最近 3 天正文，可扩大或缩小
- **世界观**：完全自定义，物价、技术、社会规则都会如实反映到正文
- **人生阶段模板**：`references/life-stage.md` 里的日常节奏可自由增删改
- **一键开局包**：`references/quick-start-packs.md` 内置 7 个包，可自由增删；欢迎把你的世界固化成新包

## 常见问题

**它会自己编出我不想要的剧情吗？**
默认下你自由输入主角的行动，剧情方向由你把控；只有拿不定主意时呼出选项、或主动开自动模式，Claude 才代为决定。它负责的始终是"结果如何"和填充真实的生活质感。

**能写黑暗/沉重的题材吗？**
支持自定义世界观。题材边界由你设定，随时可以喊停或重定向。

**正文越堆越多，会不会读不动？**
读档有明确范围上限（最近 3 天 + 最新状态 + 关系全文），老正文按需定向读取。
