# 极致真实模拟人生写作（sim-life）

"生活模拟器 + 现实主义文学"结合的写作技能。用户在虚构世界里扮演主角，Agent 以第三人称记录其人生：按天推进、维护状态文件、逐日续写，追求极致的真实感与长期一致性。

## 数据目录

所有数据保存在项目根目录的 `sim-life-data/` 下：

```
sim-life-data/
├── world.md            世界设定（时代/地点/物价/技术/社会规则/特殊设定）
├── current.md          当前指针：日期/位置/进度 + 待跟进事项
├── relations.md        关系图谱：角色间关系与里程碑
├── characters/
│   └── <角色名>.md     每个角色一个档案文件，按版本追加
├── timeline/
│   └── <YYYY-MM-DD>.md 当天简要记录（事实摘要，供快速读档）
└── 正文/
    └── <YYYY-MM>/                      按月分子目录（可按需切为周）
        └── <YYYY-MM-DD> <简要>.md      完整叙事正文，标题 = 日期 + 当天一句话摘要
```

**current.md 结构：**

```
# 当前状态
- 当前日期：
- 进行到：（当天进行到哪个环节）
- 主角：
- 当前位置：
- 待跟进事项：
  - <日期> <尚未完结的事>（例：07-08 欠张伟 300 块没还；07-09 和同事阿良闹了不愉快，还没说话）
```

> 待跟进事项是连续性的命门：吵架、欠人情、答应的事、没做完的约定都记在这里；读档时 Agent 据此把旧线自然接上。

## 核心原则

1. **真实感至上**：细节白描，拒绝戏剧化捷径。详见 `references/realism-rules.md`
2. **长期一致性**：续写前必须先读档（current.md、最新角色版本、relations.md、最近 timeline、最近 正文）
3. **决策驱动**：每天通过"3+1 选项"让用户介入，选项影响事件走向
4. **因果累积**：以前发生的事（帮助、得罪、暧昧）沉淀到状态文件，持续影响未来
5. **看不见的骰子**：Agent 按性格 + 场合 + 状态估算概率后随机落地，不显式掷骰
6. **不读档重来**：除用户明确说"重置这一天"，否则坏结果照常入档并影响后续——真实感优先于用户爽感

## 工作流程

### 阶段一：新建人生

1. 检查 `sim-life-data/` 是否存在，不存在则按上述结构创建
2. **设定世界**：与用户确认时代、地点、物价、技术水平、社会规则；写入 `world.md`（模板见 `references/world-schema.md`）
3. **捏主角**：询问性别、外貌、身材、年龄、家庭背景；可选习惯/怪癖、人生目标。确认后生成初始档案 `characters/<主角名>.md` v1（模板见 `references/character-schema.md`）
4. 创建 `relations.md` 和 `current.md`（初始日期 = 用户指定，未指定则取世界内默认；current.md 含"待跟进事项"字段，见下）
5. 告知设定完成，询问是否开始第一天

### 阶段二：每日推进

按 `references/choice-system.md` 的规则：

1. **读档**：按**读档范围**读取——current.md（含待跟进事项）、所有角色的最新版本、relations.md 全文、最近 3 天 timeline（摘要）与最近 3 天 正文（细节）；当人物与正文增多时以此为上限，防止全读导致上下文膨胀。需要更多回忆时再定向读取对应文件
2. **开场简述**：第三人称交代今天天气、主角状态、一个场景钩子
3. **逐项决策**：逐个呈现决策点，每个决策点 3 个选项 + 1 个自由输入；每个选项出现前用两三句交代当前场景
4. **提交确认**：当天决策点走完后，汇总今天走过的路，询问"今天的故事要提交吗？"（允许用户补充/修改）
5. **润色成文**：确认后，把全天选择连贯润色成完整第三人称叙事，填入日常细节；标题 = `日期 + 当天一句话摘要`（如 `2026-08-06 搬家到新公寓`），完整正文写入 `正文/<YYYY-MM>/<日期> <简要>.md`（按月分目录，Agent 按需创建当月目录）；同时把当天的事实摘要（发生了什么、因果要点）写入 `timeline/<日期>.md` 供快速读档
6. **归档**：按实际变化给受影响角色追加新版本、更新 relations.md、推进 current.md 并更新"待跟进事项"（把尚未完结的事记进去）

> **自动模式（可选）**：用户输入"今天全自动 / 自动模式"时，跳过逐项决策——Agent 用看不见的骰子替主角做出当天全部决策（含穿搭、事件应对），依据仍是角色性格、状态、关系累积与世界规则；提交前给用户当天预览（发生了哪些选择与结果），确认后照常润色归档。自动模式不影响因果累积与一致性。

### 阶段三：续写

用户说"继续"或"过一天"时：

1. 读档（同阶段二第 1 步）
2. 判断时间推进：普通日子快进（保留质感）、重要日子细写——由叙事自然度决定，也可听从用户指定
3. 按阶段二流程推进

## 关键规则速查

- **选项格式**：`A/B/C（3 个生成选项）+ 自己输入`
- **决策点数量**：平淡日 1-2 个；重大日（约会/面试/冲突）4-6 个；每天至少 1 个（穿搭）
- **穿搭影响**：内部标注醒目度与场合适配，惹眼穿着提高注意概率
- **大小事判定**：小事只叙述不记档；大事（关系建立/破裂、金钱变动、健康变化）写入新版本
- **叙述语气**：第三人称冷叙述为主，允许偶尔文学性描写；白描细节，不总结不煽情
- **不读档重来**：除用户明确说"重置这一天"，否则坏结果照常入档并影响后续
