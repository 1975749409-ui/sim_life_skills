# 世界设定模板（world-schema）

世界设定保存在 `sim-life-data/<人生名>/world.md`。

## 模板

```
# 世界设定

## 时代背景
- 年份 / 纪元：
- 大环境：

## 地理位置
- 主要地点：
- 主角常驻地点：

## 气候 / 季节
- 气候类型：
- 四季特征：（影响日常细节与事件——夏天地铁闷热、冬天下雪）

## 物价水平（真实感关键）
- 举例：一碗面 / 一次公交 / 一个月房租 / 一杯奶茶 ≈ <数字> <货币>
- 主角的收入 / 生活费大致水平：

## 技术水平
- 有什么（手机、网络、地铁…）：
- 没有 / 很贵 / 过时什么：

## 社会规则
- 习俗 / 礼仪：
- 潜规则 / 风气：
- 法律 / 底线：

## 世界大事件（时代冲击）——默认关闭，开局时询问
- 启用：<是 / 否>
- 若启用，按时间触发的时代冲击列在下面：
- <时间> <事件> <对生活的影响>（例：1993 下岗潮开始 → 厂里人心惶惶；2026 经济下行 → 裁员传闻四起；流行病 → 出行要戴口罩）

## 叙事风格（文风）
- <冷叙述（默认）/ 幽默 / 诗意 / 自定义>
- 影响正文整体语气，但不违反机制隐藏与白描规则

## 特殊设定（自定义）
- <用户自定义的一切特殊规则>
```

## 使用约定

- Agent 写作时**必须符合**物价、技术、社会规则，不能出现时代错误的细节
- 具体物价让日常记录有质感：主角会为某样东西计算钱够不够
- 天气按现实规律连续，不每天随机；季节影响事件与细节
- 世界大事件**默认关闭**：仅当用户开局时选择开启才生效（world.md 的"启用"字段记为"是"）；关闭时 Agent 不得自行引入时代冲击
- 叙事风格决定正文语气：冷叙述克制白描，幽默仍有内容，诗意仍不许出现数值；可随时修改
- 世界大事件按时间触发，作为背景板：通过新闻、物价、街景、人们的谈论自然浮现，冲击所有角色的生活与情绪
- 用户可随时要求追加特殊设定，追加后更新本文件
- 世界设定也按版本维护（追加新版本），保证设定演化的历史可追溯
- 可从 `references/quick-start-packs.md` 加载一键开局包（含世界观、主角预设、初始人物、开局情境），再按需修改
