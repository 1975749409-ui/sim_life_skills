# 身心状态系统（body-mind）

主角是活在身体里的：饿着、困着、病着、心乱着，都会改变那一天的一切。本系统追踪身心的底层状态，全部作为"看不见的骰子"的修正系数。

> **呈现铁律**：数值只存在于 current.md 与角色档案里，供 Agent 判定。正文绝不出现数值、进度条、状态标签——一切通过身体反应、行为、神态、对话自然浮现。

## 一、生理需求（饱腹 / 睡眠 / 精力）

### 追踪维度
- **饱腹**：饿 / 有点饿 / 正常 / 饱 / 撑（由今天吃了什么决定）
- **睡眠**：昨日睡了几小时、质量（失眠 / 被吵醒 / 自然醒 / 赖床 / 通宵）
- **精力**：高 / 中 / 低 / 透支（由睡眠 + 当天活动消耗决定）

### 影响（骰子修正）
- 饿着 → 烦躁、没耐心、交流易顶嘴、课上肚子咕咕叫
- 困 / 透支 → 反应慢、做事易出错、开会走神、迟到
- 睡好 + 吃饱 → 状态加成，事情办得顺、交流更耐心

### 更新
- 每顿饭后、每晚睡后更新；通宵、高强度活动消耗精力
- 存档位置：current.md 的"身心状态"小节（每日动态）

## 二、健康与疾病

### 病程
- **小病**（感冒 / 上火）：3-5 天，精力下降，需休息 / 吃药
- **大病**（发烧 / 流感 / 扭伤 / 肠胃炎）：数天至一周，需请假 / 看医生，生成待办
- **慢性 / 长期**：见 `life-stage.md` 的时间跨度过长

### 联动
- 生病 → 精力低、待办（请假 / 看医生 / 买药）、临近日程变动
- **生病时谁来看你、你照顾谁 → 好感度变化**（感情升温的真实场景，见 `relations-schema.md`）
- 恢复：按时休息、吃药、有人照顾 → 更快
- 存档：角色档案"健康"字段细化 + 病程记录（何时开始 / 预计何时好）

## 三、情绪 / 心理

### 状态（状态 + 强度，不是数值）
- 平静 / 高兴 / 低落 / 焦虑 / 兴奋 / 烦躁 / 空虚
- 强度：轻微 - 明显 - 严重

### 来源与去向
- 受事件影响：被表扬 → 高兴，吵架 → 低落，压力 → 焦虑，好消息 → 兴奋
- 随时间平复：独处、倾诉、做喜欢的事、睡一觉
- 长期低落累积 → 需要被照顾（接住 `realism-rules.md` 的"困难题材的处理"，节奏由用户掌控）

### 反作用于骰子
- 心情好 → 交流效果加成、更容易鼓起勇气
- 低落 / 焦虑 → 更容易搞砸、说话更冲、决策更冲动、记性差
- 向谁倾诉 → 关系深化、好感度变化

### 存档
- 角色档案"心情"字段记录状态与变化原因

## 呈现铁律（最高规则）

**绝不输出**数值、进度条、状态标签——不写"饱腹度 30""心情 -20"。一切通过身体反应、行为、神态、对话、环境自然浮现：

- **饿**：肚子叫、胃发慌、看什么都想啃、说话没力气
- **困**：哈欠连天、眼皮打架、咖啡续命、课上睡着
- **病**：喉咙痛、量体温、找药、咳得说不上话
- **低落**：话少、躲人、发呆、看什么都不顺眼
- **焦虑**：反复看手机、搓手指、绕圈子走

数值只存在于 current.md / 档案里，供 Agent 判定，绝不进正文。
