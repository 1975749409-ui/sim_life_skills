# 极致真实模拟人生写作（sim-life-4.0）

"生活模拟器 + 现实主义文学"结合的写作技能。用户在虚构世界里扮演主角，Agent 以第三人称记录其人生：按天推进、维护状态文件、逐日续写，追求极致的真实感与长期一致性。

## 数据目录

所有数据保存在项目根目录的 `sim-life-data/` 下，**每个"人生"一个独立存档文件夹**（可并行开多个存档）：

```
sim-life-data/
└── <人生名>/                        ← 一个存档 = 一个世界 + 一个主角
    ├── world.md            世界设定（时代/地点/物价/技术/社会规则/气候）
    ├── current.md          当前指针：日期/天气/进度 + 身心状态 + 待跟进 + 今日提醒 + 经济账本
    ├── todos.md            待办与日程：今日日程 + 短期待办 + 长期待办 + 节日纪念日 + 变化日志
    ├── threads.md          故事线追踪：主线/支线进度与下一步触发
    ├── 年表.md             人生编年史：重大节点按日期记录（含月/年回望）
    ├── relations.md        关系图谱（含圈层）：角色间关系与里程碑
    ├── characters/
    │   └── <角色名>.md     每个角色一个档案文件，按版本追加
    ├── timeline/
    │   └── <YYYY-MM-DD>.md 当天简要记录（事实摘要，供快速读档）
    └── 正文/
        └── <YYYY-MM>/      按月分子目录（可按需切为周）
            ├── 索引.md      当月正文索引（写入后自动更新）
            └── <YYYY-MM-DD> <简要>.md   完整叙事正文，标题 = 日期 + 当天一句话摘要
```

**current.md 结构：**

```
# 当前状态
- 人生名：
- 当前日期：（含周几）
- 天气：（依季节与前一天连续，不每天随机）
- 身心状态：          ← 身体与心理底层，骰子修正系数（见 references/body-mind.md）
  - 饱腹：<饿 / 有点饿 / 正常 / 饱 / 撑>
  - 精力：<高 / 中 / 低 / 透支>
  - 健康：<健康 / 小病（病程第 N 天）/ 病中（需请假）>
  - 情绪：<平静 / 低落 / 焦虑 / 兴奋 / 烦躁（附强度）>
- 进行到：（当天进行到哪个环节）
- 主角：
- 当前位置：
- 今日提醒：          ← 从 todos.md 生成，开场必读
  - <时间> <事项>（例：08:00 上课；19:30 约了李静看电影；今天要还书）
- 待跟进事项：        ← 过去未完结的事（含逾期未做的待办转过来的）
  - <日期> <尚未完结的事>（例：07-08 欠张伟 300 块没还）
- 经济账本：          ← 钱的实感，剧情发动机
  - 存款：
  - 本月已支 / 预算：
  - 负债：
  - 大额目标：（正在为 X 攒钱）
```

> **待跟进（过去）+ todos（现在与未来）+ 经济账本（当下）是连续性的三根支柱**：旧线不会丢、约定按时提醒、钱够不够始终是现实的约束。读档时 Agent 全部读取。

**todos.md 结构（待办与日程系统）：**

```
# 待办与日程（todos）

## 今日日程（当天固定安排，含时间）
- <时间> <事项>（例：08:00 上课；14:00 对需求；19:30 约了李静看电影）

## 短期待办（7 天内有固定日期/时间的约定与截止）
- <日期> <事项>（例：08-12 交周记；08-13 还张伟 300 块；周五体测）
- 状态：<未做 / 已做 / 顺延到 X>

## 长期待办（跨周或持续的义务与目标）
- <目标/义务> <状态>（例：攒 5000 买缝纫机·进行中；报名下月考试·未报名；答应奶奶周末回家·未定日期）

## 节日 / 纪念日（那天自动成为重要日子）
- <日期> <谁的生日 / 什么节日 / 认识第 N 年>（例：09-14 奶奶生日；腊月廿三 小年；05-20 与李静认识一周年）

## 变化日志（每次增改记一笔）
- <日期> <新增 / 完成 / 修改> <事项>
```

> **每日提醒规则**：每天开场简述先读"今日日程"+"短期待办"里今天要处理的，明确提醒用户（时间 + 事项）；当天的约定随时入账；逾期未做的转到 current.md 的"待跟进事项"。

**threads.md 结构（故事线追踪）：**

```
# 故事线追踪（threads）

## 主线（1-2 条）
- <线名>：<简述>
  - 进度：<进行到哪>
  - 下一步触发：<什么事件会推进这条线>
  - 相关角色 / 地点：

## 支线（数条）
- <线名>：<简述>
  - 进度：
  - 下一步触发：
  - 相关角色 / 地点：

## 完结 / 搁置
- <线名>：<何时、何因结束>
```

> 故事线防止重要的事被忘；多条线交织推进 = "各方面影响共同作用"。线头来自主角的人生目标 / 执念 + 开局情境的钩子。

**年表.md 结构（人生编年史 + 一生统计）：**

```
# 人生编年史（年表）

## 编年史
- <日期> <重大节点>（例：08-09 入职新公司；09-14 奶奶生日全家吃饭）

## 人生数据（一生统计，归档时累计）
- 认识的人数：
- 帮过 / 被帮过的次数：
- 最高存款：
- 去过的地方数：
- 看过的日落 / 熬过的夜：
- 搬过的家 / 换过的工作：
- 谈过的恋爱 / 断掉的关系：
```

> 编年史记节点，统计记总量；两者在导出传记时一同呈现。

## 核心原则

1. **真实感至上**：细节白描，拒绝戏剧化捷径。详见 `references/realism-rules.md`
2. **长期一致性**：续写前必须先读档（current.md、最新角色版本、relations.md、最近 timeline、最近 正文）
3. **沙盒自由**：默认自由行动——Agent 连续叙事，用户随时自由输入行动，骰子决定结果；选项是召唤式辅助
4. **因果累积**：以前发生的事（帮助、得罪、暧昧）沉淀到状态文件，持续影响未来
5. **看不见的骰子**：Agent 按性格 + 场合 + 状态估算概率后随机落地，不显式掷骰
6. **不读档重来**：除用户明确说"重置这一天"，否则坏结果照常入档并影响后续——真实感优先于用户爽感
7. **成长与时间**：能力、经济、健康随岁月真实推进，人生阶段决定日子的形态（学生、上班族、退休的日子结构不同）
8. **时间纵深**：年表记录重大节点，月末/年末生成回望；年龄、健康随岁月推进，终局（离世）也是人生的一部分
9. **好感度系统**：关系有双向数值（-100~100），受颜值初印象、交流、互动、时间、圈层口碑影响，并通过看不见的骰子作用于结果（见 `relations-schema.md`）
10. **身心底层**：生理（饱腹/睡眠/精力）、健康疾病、情绪心理都作为骰子修正系数——身体状态决定一天的质量（见 `references/body-mind.md`）
11. **机制隐藏**：所有系统（好感度/身心/经济/世界大事件/故事线…）只存在于档案与判定中，正文一律行为化呈现，绝不输出数值、进度条或状态标签

## 工作流程

### 阶段一：新建人生

1. 检查 `sim-life-data/` 是否存在，不存在则创建；**新建人生**时向用户询问人生名（存档名），创建 `sim-life-data/<人生名>/` 结构；**续写**时列出已有存档供选择
2. **快速开局（点开即玩）**：先问用户要不要用预设包。要的话列出 `references/quick-start-packs.md` 的全部开局包（世界观 + 主角预设 + 初始人物 + 开局情境），用户选一个或说"**随机**"（Agent 随机抽一个包，或即兴生成一个自洽的世界 + 主角 + 主线），一键写入 world.md（含世界大事件与文风）、主角 v1、初始人物档案、current.md（含开局身心状态/待跟进/临近日程/经济）、todos.md、threads.md（主线线头），然后直接开始第一天（用户可先微调再开玩）
3. **从零设定**：用户不用预设包时，自建世界与主角——
   - **设定世界**：与用户确认时代、地点、物价、技术水平、气候、社会规则、**叙事风格**（冷叙述默认 / 幽默 / 诗意）；写入 `world.md`（模板见 `references/world-schema.md`）
   - **捏主角**：询问性别、外貌、身材、年龄、家庭背景、**人生阶段**（见 `references/life-stage.md`）、**说话方式**、**兴趣/技能**；可选习惯/怪癖、人生目标。确认后生成初始档案 `characters/<主角名>.md` v1（模板见 `references/character-schema.md`）
4. **世界大事件开关**：询问用户是否开启"世界大事件"（时代冲击：下岗潮 / 裁员潮 / 流行病…）——**默认关闭**。开启则写入 world.md 并按其时间轴触发；关闭则系统休眠，Agent 不得自行引入时代冲击
5. 创建 `relations.md`、`todos.md`、`threads.md` 和 `current.md`（初始日期 = 用户指定或世界内默认；current.md 含身心状态、今日提醒、待跟进事项、经济账本、当日天气；threads.md 从主角目标与开局钩子初始化主线）
6. 告知设定完成，询问是否开始第一天

### 阶段二：每日推进

默认交互为**沙盒自由模式**（见 `references/sandbox-mode.md`），选项是召唤式辅助（见 `references/choice-system.md`）：

1. **读档**：按**读档范围**读取——current.md（含身心状态、今日提醒与待跟进）、todos.md、threads.md、所有角色的最新版本、relations.md 全文、最近 3 天 timeline（摘要）与最近 3 天 正文（细节）；当人物与正文增多时以此为上限，防止全读导致上下文膨胀。需要更多回忆时再定向读取对应文件。**记忆检索**：正文需要调用较久以前的旧事时，不得凭空编造——按日期/关键词定向搜索对应 timeline 与正文，找到事实再写；找不到就让角色"记得不清"（见 realism-rules 的记忆检索协议）
2. **开场简述**：先按 `todos.md` 的**今日日程与待办**提醒用户——今天几点上课/上班、约了谁几点见、近期要交什么（时间 + 事项，明确不遗漏，语气融入叙事）；再交代今天天气、**身心状态**（困倦/饥饿/病中/情绪，自然带出不硬塞）、主角状态、场景钩子；**日子的骨架服从主角的人生阶段**（模板见 `references/life-stage.md`）；若有临近的短期待办（如明早面试），提前埋下铺垫（今晚失眠）；若世界大事件正在发生，通过新闻/物价/街景/人们的谈论自然浮现在背景里
3. **沙盒推进**：Agent 连续叙事当天，在每个有意义的节点自然停顿，邀请用户自由行动；用户输入的一切是**权威行动**，骰子决定结果；用户说"给我几个选项"时才亮出 A/B/C（规则见 `references/choice-system.md`）
4. **提交确认**：一天走完后，汇总今天走过的路，询问"今天的故事要提交吗？"（允许用户补充/修改）
5. **润色成文**：确认后，把全天选择连贯润色成完整第三人称叙事，填入日常细节；标题 = `日期 + 当天一句话摘要`（如 `2026-08-06 搬家到新公寓`），完整正文写入 `正文/<YYYY-MM>/<日期> <简要>.md`（按月分目录，Agent 按需创建当月目录），并更新当月 `索引.md`；同时把当天的事实摘要（发生了什么、因果要点）写入 `timeline/<日期>.md` 供快速读档。**若今天跨过月末或年末，额外生成一篇"回望"**——主角视角回顾这一段岁月（含糊、偏颇、突出重点与遗憾），存入当月正文目录
6. **归档**：按实际变化给受影响角色追加新版本（含能力成长、说话方式一致性、年龄推进、身心变化）、更新 relations.md（含**双向好感度与影响因子**、圈层与情感倾向）、更新 **todos.md**（今天新约的约定即入账、完成的划掉、逾期未做的转待跟进；节日/纪念日登记）、推进 **threads.md**（故事线进度与下一步触发）、推进 current.md 并更新**身心状态 / 待跟进事项 / 今日提醒 / 经济账本 / 天气**；**跨月时做月度经济结算**（收入入账、固定支出扣款、通胀）；检查**世界大事件**是否触发（仅开关开启时，见 world.md）；重大节点写入 `年表.md`（并累计其中的**一生统计**：认识的人、最高存款、去过的地方等）；主角长时间未接触的角色，可为其补充"离线近况"并结算好感衰减（合理推演，见 relations-schema）
7. **一致性自检**：归档后快速核对——current.md 的日期/位置、各角色最新版、relations、timeline、年表是否自洽；**角色口吻抽查**——抽查当天对话是否符合各角色档案的"说话方式"（口头禅/句式/语速）；发现不一致当场修正或追加勘误，不让错误悄悄累积

> **自动模式（可选）**：用户输入"今天全自动 / 自动模式"时，跳过自由行动——Agent 用看不见的骰子替主角做出当天全部行动（含穿搭、事件应对），依据仍是角色性格、状态、关系累积与世界规则；提交前给用户当天预览（发生了哪些行动与结果），确认后照常润色归档。自动模式不影响因果累积与一致性。**三种交互（沙盒 / 选项 / 自动）随时可切换。**

### 阶段三：续写

用户说"继续"或"过三天/过一周"时：

1. 读档（同阶段二第 1 步）
2. 判断时间推进：普通日子快进（保留质感）、重要日子细写——由叙事自然度决定，也可听从用户指定
3. **多天推进**：每天独立成一篇正文、逐日归档；连续平淡日可开自动模式批量生成，但正文仍按天分开，timeline 摘要可合并为一条
4. **人生阶段切换**：毕业、入职、结婚、退休、伤病等重大节点发生时，切换对应人生阶段的日常模板，并在主角档案追加新版本注明阶段变化
5. **跨年份与终局**：时间跨过多年时，年龄与健康如实推进（见 `life-stage.md` 的"时间跨度过长"）；若主角或重要角色离世，按终局规则归档，让余下世界继续受影响
6. 按阶段二流程推进

### 阶段四：导出 / 传记模式

用户要求"导出 / 传记"时：

1. 把指定时期（某月 / 某年 / 全篇）的正文按时间顺序拼接为一份完整文档
2. 文档含：人物表（从 characters/ 提取）、世界背景（world.md 摘要）、完整正文、年表附录（含一生统计）
3. 生成可通读、可分享的"传记"文件（如 `传记.md` 或用户指定路径）
4. 只读取与拼接，不改动任何存档文件

## 关键规则速查

- **沙盒自由**：默认连续叙事 + 自由输入行动，骰子管结果；说"给我几个选项"才亮选项
- **快速开局**：选 `quick-start-packs.md` 的开局包一键开玩（世界观 + 主角 + 初始人物 + 开局情境）
- **好感度**：双向 -100~100，受颜值/交流/互动/时间/圈层口碑影响；只通过行为显现，正文不出现数字
- **待办提醒**：每天开场按 todos.md 提醒今日日程与待办（时间+事项）；当天新约定即入账；逾期转待跟进
- **身心状态**：饱腹/睡眠/精力 + 健康疾病 + 情绪，都是骰子修正系数（见 body-mind.md）
- **故事线**：threads.md 追踪主线/支线进度与下一步触发，防线被忘
- **月度结算**：跨月时结算收支与通胀
- **世界大事件**：默认关闭，开局时询问；开启才按时间轴触发时代冲击
- **机制隐藏**：所有数值/状态只在档案里，正文一律行为化呈现
- **随机开局**：说"随机"即自动生成世界+主角+主线，无需挑选
- **文风**：world.md 的叙事风格（冷叙述/幽默/诗意）决定正文语气，随时可改
- **记忆检索**：调用旧事时定向搜索正文/timeline，不凭空编造
- **一生统计**：年表里累计人生数据，导出传记时呈现
- **口吻抽查**：自检时核对对话是否符合角色说话方式
- **人物演化**：性格/爱好随经历变化，字段旁标（日期·事件）
- **选项格式**（呼出时）：`A/B/C（3 个生成选项）+ 自己输入`；3 个选项须至少含一个"平凡/怯懦/可能后悔"的选项
- **决策点数量**（呼出时）：平淡日 1-2 个；重大日（约会/面试/冲突）4-6 个；每天至少 1 个（穿搭）
- **穿搭影响**：内部标注醒目度与场合适配，惹眼穿着提高注意概率
- **大小事判定**：小事只叙述不记档；大事（关系建立/破裂、金钱变动、健康变化）写入新版本
- **叙述语气**：第三人称冷叙述为主，允许偶尔文学性描写；白描细节，不总结不煽情
- **不读档重来**：除用户明确说"重置这一天"，否则坏结果照常入档并影响后续
- **勘误**：记错了事实就追加勘误版本/勘误说明，不改写原文
- **版本封档**：角色档案旧版本按月压缩为历史摘要，防文件膨胀
- **正文索引**：每月 `正文/<月>/索引.md` 自动维护
- **事件池**：随机事件从 `references/event-pool.md` 抽取，防重复套路
- **插曲**：每天小概率插入打断节奏的突发事件（见 choice-system）
- **回望**：月末/年末自动生成一篇主角视角的回望
- **自检**：归档后核对各文件一致性
- **导出**：可把正文拼接成完整传记文档
