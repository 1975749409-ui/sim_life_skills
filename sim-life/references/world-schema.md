# 世界设定模板（world-schema）

世界设定保存在 `sim-life-data/world.md`。

## 模板

```
# 世界设定

## 时代背景
- 年份 / 纪元：
- 大环境：

## 地理位置
- 主要地点：
- 主角常驻地点：

## 物价水平（真实感关键）
- 举例：一碗面 / 一次公交 / 一个月房租 / 一杯奶茶 ≈ <数字> <货币>
- 主角的收入 / 生活费大致水平：

## 技术水平
- 有什么（手机、网络、地铁…）：
- 没有 / 很贵 / 过时什么：

## 社会规则
- 习俗 / 礼仪：
- 潜规则 / 风气：
- 法律 / 底线：

## 特殊设定（自定义）
- <用户自定义的一切特殊规则>
```

## 使用约定

- Agent 写作时**必须符合**物价、技术、社会规则，不能出现时代错误的细节
- 具体物价让日常记录有质感：主角会为某样东西计算钱够不够
- 用户可随时要求追加特殊设定，追加后更新本文件
- 世界设定也按版本维护（追加新版本），保证设定演化的历史可追溯
