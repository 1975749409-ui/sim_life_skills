# 人生阶段日常模板（life-stage）

主角的"一天"由人生阶段决定。捏人时确定阶段；阶段切换是重大节点（毕业 / 入职 / 结婚 / 退休 / 伤病），切换时在主角档案追加新版本注明，并改用对应模板。

模板是**节奏参考，不是剧本**：它决定一天的骨架（几点起床、白天干什么、晚上怎么过），细节仍由事件、选择与看不见的骰子填充。

## 阶段模板

### 学龄前 / 儿童
- 被家长叫醒、赖床、穿衣服磨蹭
- 上幼儿园 / 小学低年级、课间打闹、被老师点名
- 放学、零食、看动画片、写作业磨蹭
- 被催洗澡、睡前听故事 / 玩玩具

### 学生（小学 / 中学 / 大学）
- 按课表走：早自习 / 第一节到最后一节、课间、午休
- 考试周 / 补作业 / 被提问答不上来
- 社团、恋爱、兼职、和同学约饭
- 中学：补习班、晚自习、被家长问成绩
- 大学：食堂、宿舍、选修课、夜晚宿舍卧谈、ddl 前熬夜
- 周末 / 寒暑假：补课 or 出去玩，取决于是谁

### 在职上班族
- 闹钟响、赖床、通勤（挤地铁 / 堵车）
- 上班：摸鱼、开会、被分配活、午休拼饭
- 下班：准点 or 加班
- 回家做饭 or 外卖、刷手机、洗澡、睡觉

### 自由职业 / 失业 / 待业
- 没有强制时间表：睡到自然醒
- 投简历、接活、改方案、对着电脑发呆
- 焦虑与无聊交替：白天恹恹，晚上睡不着
- 收入不规律，经济账本格外敏感

### 退休 / 老年
- 早起遛弯、买菜、早点摊
- 和老朋友下棋 / 广场舞 / 公园打牌
- 体检、吃药、午睡、看子女发来的消息
- 体力衰退与病痛是日常背景，节奏慢

### 临时特殊状态
- 住院、旅行、搬家、备考冲刺期等，按情境定制当天节拍

## 切换规则

- 阶段变化由重大事件触发：毕业典礼 → 职场；裁员 → 失业；结婚 → 家庭；退休 → 老年
- 切换时更新角色档案的"人生阶段"字段，并让日子骨架随之改变（第一周往往有适应期的笨拙）
- 学生假期（寒暑假、节日）临时改变学生模板
- 例外与临时状态结束后，回到原阶段模板

## 时间跨度过长 / 终局

- **年龄推进**：跨过生日时年龄 +1，并在档案新版本更新；外貌、体力、健康随之缓慢变化（青年 → 壮年 → 中年 → 老年）
- **重大健康事件**：疾病、意外会改变健康状况与人生阶段（如大病后提前退休）
- **主角离世**：人生结束——生成一篇"终局"正文（最后一程、回忆与告别），之后可开新存档，或让世界以"后人回望"的视角收束
- **重要角色离世**：归档离世（出生/死亡日期、纪念），主角与圈层的关系随之改变（悼念、遗产、空缺感），并在后续正文中自然体现
- **终局不戏剧化、不升华**：像真实死亡一样安静而具体
