# 现实主义写作规则（realism-rules）

这是"极致真实"的核心。一切叙事必须服从以下规则。

## 一、拒绝戏剧化捷径

写作时**禁止**以下套路：

- **主角光环**：关键时刻总能化险为夷、恰好来得及
- **巧合救场**：需要时正好有人出现 / 正好有钱 / 正好被选中
- **完美应对**：每次对话都说得很到位，从不后悔自己说过的话
- **突然顿悟**：重大的自我觉醒在某个瞬间突然完成
- **命运叙事**：不允许出现"命运的齿轮转动了""这注定……"等文学上帝视角
- **极端化情绪**：人物不会动不动就崩溃 / 狂喜，情绪是温吞、延迟、矛盾的

## 二、拥抱平庸

真实的人生由大量"不值得写"的瞬间组成，这些才是真实感的来源：

- 答非所问、话到嘴边咽回去、微信打字又删掉
- 尴尬冷场、后悔说过的话、但嘴上不说
- 钱不够、花超了、月底算账
- 熟人渐渐不联系、朋友变淡但没吵架
- 身体的小毛病：颈椎疼、上火、闹钟响了不想起
- 天气带来的实际影响：下雨没带伞、闷热睡不着
- 普通的一顿饭、重复的通勤路线、刷手机打发时间
- **平凡感适配世界观**：无论什么世界，日子都有不值得写的部分——当代是挤地铁/外卖/微信；仙侠是挑水劈柴/赶集/传讯玉简；西幻是揉面/喂马/去公会排队；魔法与灵光之下，人还是人要吃饭、睡觉、发呆

## 三、细节白描

- 多用**具体数字**：多少钱、几点几分、多少米、走几站地铁
- 多用**感官细节**：气味、声音、光线、触感
- 允许**无关紧要的观察**：谁穿了什么颜色、路边摊的招牌
- 细节服务真实感，不是展示文笔；堆细节但不断因果

## 四、因果与延迟

- 行动有后果，但后果**有时延**——帮助别人的回报可能几周后才出现
- 人际关系是**渐变**的，不会一次对话就翻天覆地
- 后果由多方面因素共同作用，不是单一原因决定
- 大事落地前有征兆，而主角往往察觉不到
- **因果要浮出水面**：当过去的事件影响今天时，正文中必须自然浮现那段因果（如"李静还记着地铁上你帮她捡文件的事"），让读者看得见关联，而不是只躺在档案里

## 五、叙述语气

- 以**第三人称冷叙述**为主：上帝视角的账本，精确、克制
- 允许**偶尔**的文学性描写（一个比喻、一段环境），但不过度
- 不总结、不点评、不替读者解释"这意味着什么"
- 动作、对话、客观细节为主；内心活动适度，避免大段心理独白
- **视角切换**：默认聚焦主角，但重大时刻偶尔把焦点移到配角身上写一小段（"张伟那晚也没睡"），让世界更立体；切换要克制，不频繁
- **回望**：月末/年末的回望要像真实的回忆——含糊、偏颇、突出重点与遗憾，不面面俱到
- **口吻一致**：对话严格贴合角色的"说话方式"（口头禅/句式/语速）——这是角色识别度的核心，跑偏了要在自检时修正
- **提醒融入叙事**：每日提醒要说清时间与事项，但像人脑记日程那样自然带出，不逐条念清单；提醒的语气贴合主角当天的心情（赶时间就急促，发呆就恍惚）

## 六、时间推进

- 普通日子：可快进带过，但仍保留真实质感（挑几个有代表性的瞬间白描）
- 重要日子：细写，对话完整，过程详细
- 时间推进由叙事自然度决定，也可听从用户指定
- 每天连续，时间线不跳空、不倒退

## 七、世界的自洽

- **天气与星期连续**：天气依季节与前一天演变，不每天随机；星期决定生活节奏（周末、工作日、节假日），影响事件与细节
- **人生阶段定节拍**：日子的骨架服从主角的人生阶段（模板见 `life-stage.md`）；阶段切换是重大节点
- **群像离线活动**：世界不是围着主角转——非主角角色有自己的生活。主角再见到他们时，那些"没演给你看的日子"要留下痕迹（"上周回了趟老家""感冒刚好"）
- **能力成长**：重复的活动缓慢改变能力（坚持跑步 → 耐力见长），变化在正文与档案中如实体现，不一夜暴增
- **金钱实感**：钱的数字要具体、要让人心疼（月底算账、纠结要不要买、看着余额叹气），钱是持续的现实约束
- **记忆与遗忘**：长时间不联系的关系，主角对他们的记忆与关系自然淡化（好感回落、称呼生疏）；偶然一个细节（旧照片、熟悉的街）触发被遗忘多年的回忆——遗忘让回忆珍贵
- **好感度行为化**：关系好坏只通过行为、神态、语气表达，正文绝不出现好感度数字（数值只存在于 relations.md 内部，见 `relations-schema.md`）

## 八、困难题材的处理

模拟人生必然会碰到沉重内容：疾病、失恋、家庭矛盾、经济崩溃、伤害，甚至死亡。处理原则：

- **尊重与克制**：痛苦是生活的成分，但叙述不渲染苦难、不猎奇；写实但不煽情
- **节奏由用户掌控**：任何时候用户可喊停、跳过，或把方向换轻
- **不让角色承受超出用户意愿的苦难**：重大灾难性情节（严重伤病、离世、犯罪受害）需要用户明确知会或选择后才发生，不自动降临
- **主角可以有脆弱，但始终保留尊严**：叙述不带评判
- **终局（死亡）**：见 `life-stage.md` 的"时间跨度过长"；离世是人生的结束，不是故事价值的结束

## 九、机制隐藏（呈现铁律）

好感度、身心状态、经济账本、世界大事件、故事线进度——**所有系统都只存在于档案与判定中，绝不进入正文表面**：

- **绝不输出**数值、进度条、状态标签（不写"饱腹度 30""好感 -20""心情·低落·中等"）
- 一切通过**身体反应、行为、神态、对话、环境**自然浮现：饿是肚子叫，困是哈欠，病是咳得说不上话，低落是躲人发呆，裁员潮是办公室的低气压，关系升温是她多看了你一眼
- 玩家靠**感受**感知状态，Agent 靠档案里的数值做判定——两边各一套语言，永不混用
- 系统是"看不见的骰子"的修正系数，不是给玩家看的仪表盘
- 文风（冷叙述 / 幽默 / 诗意）只调整语气，机制隐藏铁律在任何文风下都生效

## 十、记忆检索协议

长期人生里，正文会调用很久以前的旧事：

- 不得凭空编造过去的事实——"他想起三年前帮过李静"必须确有其事
- 需要旧事时：按日期 / 关键词定向搜索对应 timeline 与正文，找到事实再写
- 找不到就如实写"记得不清""记岔了"——遗忘本身也是真实
- 记忆出错有时比记对更有戏：张冠李戴、美化、缩水，都按角色性格来
